Here are some of the projects I've worked on, ranging from Python applications to desktop and mobile development.

## Projects

### Citrus — Encryption & Steganography

**Python · Flask · Cryptography**

A project exploring encryption and steganography techniques using Python.

The repository includes demonstrations of RSA encryption with OAEP padding and a Vigenère cipher combined with ASCII art steganography. It also explores using Flask endpoints for encryption and decryption.

[View on GitHub](https://github.com/vilvee/citrus)

---

### All-You-Can-Eat Sushi Ordering App

**C# · .NET · WPF**

A Windows desktop application project for managing orders in an all-you-can-eat sushi restaurant.

Designed around menu browsing, order placement, and tracking order status through a graphical interface built with Windows Presentation Foundation (WPF).

[View on GitHub](https://github.com/vilvee/All-You-Can-Eat-Sushi-Ordering-App)

### Moodify — Mood Tracking Application

**Kotlin · Android**

A collaborative student project focused on mood tracking and personal wellness.

The application explores daily mood logging, journaling, gratitude entries, wellness resources, and visualizing mood patterns over time.

**Team project** — Developed with three other students.

[View on GitHub](https://github.com/vilvee/Moodify)
